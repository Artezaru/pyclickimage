pyclickimage.annotation_session#

class pyclickimage.annotation_session.AnnotationSession[source]#

Bases: object

Manage a multi-image annotation session.

An AnnotationSession stores the complete state of an annotation project, including loaded images, annotation groups, current selections, and output formatting options.

Each image is represented by an ImageEntry containing:

  • the image file path,

  • the associated ClickManager.

Notes

The session object manages the relationship between images and groups. ClickManager objects only store annotation data and do not manage global session state.

class pyclickimage.annotation_session.ImageEntry(path: Path, click_manager: ClickManager)[source]#

Bases: object

Store an image and its associated annotations.

An ImageEntry links an image file path with the ClickManager responsible for storing its annotation points.

Parameters:

  • path (pathlib.Path) – Path to the image file.

  • click_manager (ClickManager) – Manager storing annotation clicks associated with this image.

Notes

Each image in an AnnotationSession owns a dedicated ClickManager. This avoids maintaining separate synchronized containers for images and click managers.
